🚛 Transport Company Management System

A professional Transport Company Management System designed to help manage vehicles, drivers, trips, customers, expenses, and transport operations efficiently.

📌 Features

* 🚚 Vehicle Management
* 👨‍✈️ Driver Management
* 📦 Transport & Shipment Management
* 🧾 Customer Management
* 💰 Expense & Payment Tracking
* 🛣️ Trip Management
* 📊 Transport Reports
* 🔐 Secure & Easy-to-Use System
* 📱 Responsive Design

🎯 Purpose

This project is designed to simplify daily transport business operations and keep important transport records organized in one place.

🚀 Getting Started

1. Clone the Repository

git clone <YOUR-REPOSITORY-URL>

2. Open the Project

cd transport-company

3. Install Dependencies

npm install

4. Start the Project

npm run dev
